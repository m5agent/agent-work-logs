## 结论

新版 Skill 从页面目标和内容顺序入手，提供官网设计证据、产品图文构图、响应式和状态变化规则。三份可运行示例分别覆盖营销页、设备控制台和文档页。浏览器在五种视口宽度运行三份示例，观察到导航、文档锚点以及控制台筛选和刷新按预期工作。

## 关键证据

- 在 1440、1024、768、390 和 320 CSS px 运行三份示例，确认页面主体无横向溢出。营销与文档导航的键盘打开、Escape、焦点返回和触屏外部关闭通过。
- 产品展台验证了默认静止、手动切换、显式播放、切换时舞台几何稳定，以及动态启用减少动效后停止轮播。阻断 3 次图片请求时，文字和控件仍可用。
- 文档另测了 860 与 820 CSS px 的菜单和目录断点，确认目标标题获得焦点且未被顶栏覆盖。320 CSS px 禁用脚本后，导航和目录链接仍可用。
- 控制台初始有 5 行示例设备。筛选离线有 2 行。同步期间观察到忙碌状态，结果更新后保留筛选区、焦点和滚动。失败场景保留 5 行并可重试恢复。
- 发布版为 2.0.1。Hub 目录、详情、下载包和本机安装一致。逐字节核对 23 个文件，并用下载包复测手机端三条路径。
