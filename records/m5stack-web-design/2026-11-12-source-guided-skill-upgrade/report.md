# M5Stack Web Design Skill 官网设计规则升级报告

## 背景

旧版 Skill 主要通过颜色、字体和通用组件传递品牌风格。用户反馈实际生成的页面仍缺少官网的信息组织、响应式编排、动效和状态细节。旧版示例实测也有行为缺口。390px 主菜单按 Escape 后仍展开，控制台查询无匹配项后仍显示原 5 行。此次从官网前端模板、样式和交互实现提炼可复用的规则，为产品展示、设备控制台和文档分别提供可执行的页面配方与示例。

## 结论

官网的主要结构特征包括按用户决策顺序排列内容，硬件画面占据首要位置，对齐宽幅内容轨，白底与浅灰大面交替，桌面分组导航在手机上改为按层展开。新版把这些规则放在入口和示例前部，同时修正旧版对 750px、1440px 和超宽视口下官网根字号变化的说明。

动效规则描述触发、可见结果、如何结束及减少动效时的行为。保留官网的图像裁切区内缩放、分段进度和与硬件结构有关的局部展示。官网未给出控制台更新、键盘焦点和减少动效的完整做法。新版控制台按真实操作顺序设计，动效回退参考 Apple 与 WebKit 的公开说明。 [Apple HIG Motion](https://developer.apple.com/design/human-interface-guidelines/motion) · [WebKit Responsive Design for Motion](https://webkit.org/blog/7551/responsive-design-for-motion/)

## 改动范围

- 入口增加工作顺序、按页面目的选择示例、手机交互和浏览器验收。官网源码依据注明模板和样式定位，单独说明迁移到工具界面所做的适配。
- 营销示例展示独立的产品画面、分段切换控件、图文叙事及相关入口。文档示例提供可到达的锚点、窄屏目录、键盘和无脚本回退。
- 设备控制台示例使用可操作的筛选和局部刷新，展示加载、空结果和失败重试。示例中的设备及状态用于复现界面行为。
- Skill 版本为 2.0.1。Hub 目录与详情显示更新计数从 1 到 3，重新下载的 23 个文件与发布包及本机安装逐字节一致。

## 执行与复现

从待验证版本的 Skill 目录运行以下命令，示例可直接在浏览器打开，无需构建。

```sh
python3 -m webbrowser -t "file://$(pwd)/examples/landing/index.html"
python3 -m webbrowser -t "file://$(pwd)/examples/dashboard/index.html"
python3 -m webbrowser -t "file://$(pwd)/examples/docs/index.html"
```

1. 用浏览器设备工具分别设置 1440、1024、768、390 和 320 CSS px。检查标题可见，整页无横向溢出。测试移动菜单的 Enter、Tab、Escape、焦点回归及触屏点击外部关闭。
2. 在文档页展开“本页目录”，选择“上报接口”。确认地址片段更新、标题获得焦点且未被顶栏遮挡。窄屏禁用脚本后检查主导航和目录链接。
3. 在营销页切换产品并暂停，再启用系统减少动态效果。检查手动操作、正文可读性及主要去向。阻断图片加载时重复读取和切换。
4. 在控制台选择离线设备和无匹配查询，分别观察 2 行与空态。清除筛选，向下滚动后用键盘触发刷新，观察忙碌状态、结果变化、滚动与焦点。使用控制台示例的 `?state=error` 进入失败场景，确认旧结果仍在，按 Enter 重试。

自动检查使用 Playwright 1.63.0。白字主按钮在 Chrome 的默认、悬停和按下状态测得 5.41、5.83、5.52:1，对应键盘输入框焦点为 2px 实线。证据汇总列出实际浏览器版本、输入和结果。 [浏览器验证摘要](evidence/browser-summary.json)

## 验证边界

浏览器结果覆盖随包示例及测过的互动。设备控制台的响应由示例数据触发。Firefox、Safari、实体手机和第三方业务接入未执行。使用 GPT-5.6 Luna（low）按同一简报分别生成 1.0.0、2.0.0、2.0.1 的控制台原型，每版一次。在 1440、390、320 CSS px 运行三份页面。2.0.1 生成物读取了控制台示例的 HTML 和状态函数，主操作移至筛选前，并在同步后保留原按钮的键盘焦点和离线筛选。三份生成物都重建了结果行，随包控制台示例则保留原行。对照仅覆盖该控制台任务。 [生成对照摘要](evidence/model-transfer-summary.json)

## 风险与回滚

保留发布前的 Skill 包。若新规则造成既有页面采用不合适的营销结构，可在同一版本管理路径恢复上一份 Skill 包，随后回读版本并重跑示例。更新对象为 Skill 文件及示例。
