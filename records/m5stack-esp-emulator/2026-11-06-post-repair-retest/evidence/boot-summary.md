## Method notes

- Each round is a cold session: wrapper composes the refreshed latest base with the R3 boot probe into a fresh image, uploads it through `/api/v1`, runs a visible QEMU session on the repaired native runtime, captures serial/frame evidence, requests the evidence ZIP before stopping, stops with `purge=0`.
- PASS requires: wrapper exit 0 / report `EXECUTED`, `LATEST_BOOT_DONE`, `LATEST_UNAME` with the expected 2026-10-30/2026-11-03 build, `LATEST_BOARD`, `LATEST_DISPLAY` matching the tracked matrix expected native size (documented StopWatch canvas exception), report `base_sha256` equal to the refreshed manifest sha256, session `runtime_binary_sha256` equal to the repaired campaign runtime for that backend, and terminal `stopped` cleanup.
- UART0 observation markers (repair class #180/#181/#182/#187 evidence): ROM banner, MicroPython banner, REPL prompt, ready marker, probe-start marker, uname/board/display/done markers all captured from the virtual UART0 controller. Device-specific `*_ui_test` markers belong to the D2 matrix scope.
- Bootstrap: default dupterm first; on the observed AtomS3-class `OSError (-259, ESP_ERR_INVALID_STATE)` the wrapper is retried once with `--uart-repl-bootstrap native` (recorded per device as `bootstrap`).
- No tracked file was modified; all derived tooling/evidence stay under `.work/retest-20261106/`.
