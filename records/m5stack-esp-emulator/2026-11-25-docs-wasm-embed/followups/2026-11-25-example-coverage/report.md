# 演示可行性

同源隔离文档预览中，两款基准固定示例约 12–24 秒到可操作应用。CoreS3 完整画面比串口 ready 晚 1.86 和 2.62 秒。等待完整界面后立即点击，两次都有实际来宾回调与像素变化。390 CSS px 宽度下，工作台没有横向溢出，启动按钮位于内层预览顶部以下约 1,900 px。文档应首发精简、固定固件版本和素材的示例，在实际应用画面出现后开放输入。先从 CoreS3 图形、触摸、按钮和 Cardputer-Adv 显示、键盘试点。启动时间限桌面本地样本。

| 范围 | 实际验证 | 边界 |
| --- | --- | --- |
| CoreS3 Arduino 15 | 构建 15，默认浏览器 4 PASS、6 PARTIAL、5 FAIL | 音频、定时唤醒、SD 素材或外设刺激仍需专用预览配置 |
| Cardputer-Adv Arduino 11 | 构建 11，默认浏览器 0 PASS、2 PARTIAL、9 FAIL | 最新库触发板型识别问题。固定最低库与 8 MiB 正控通过图形、键盘、装卡存储 |
| CoreS3 ESP-IDF BSP 4 | 四例出现应用串口活动 | 四例保持黑屏。Music 大分区修正覆盖构建及进入应用 |
| UIFlow2 208 Python + 2 Blockly | 68 个板载、M5UI、软件系统，31 个外设代表实际进入来宾检查 | 32 见可见帧，33 未见画面变化，22 有来宾报错或警告，12 有运行器错误 |
| Arduino 附件教程 | 79 页由 CoreS3 驱动，2 页由 ADV 驱动 | 两个代表 CoreS3 Unit 通过实际控制器与像素检查，其他附件仍待单项执行 |

UIFlow2 范围使用文档明确型号、实际 Python 包含和关联工程的目标类型。140 个外设示例缺默认浏览器数据路径，其中 109 个未向来宾发送原脚本。两项 Blockly 只有工程文件，预览生成与同步尚待接入。普通未指明型号教程、实物配置或外部服务指南也没有计入直达执行样本。附件和不同编程语言的示例可以覆盖同一功能，计数各自保留。

正式文档嵌入、移动端和其他浏览器仍待验收。实际 RF、声学、光学、电气与真机行为没有测试。逐例文件标注可复查的源码、实际输出和边界。
