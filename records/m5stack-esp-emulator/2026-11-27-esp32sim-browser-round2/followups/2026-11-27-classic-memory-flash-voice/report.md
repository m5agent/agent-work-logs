# Additional browser guest cases

- StickC Plus2 and Core2 run the same ESP-IDF memory algorithm. StickC Plus2 boot verified 8 MiB Flash, 2,097,152 bytes PSRAM and readback at both ends of a 2,064,384-byte guest allocation. Core2 verified 16 MiB Flash, 8,388,608 bytes PSRAM and independent seed readback on HIMEM pages 127, 128 and 255. The initial StickC Plus2 fixture was rejected by the browser before start because its original build declared 16 MiB Flash. Rebuild the fixture with `CONFIG_ESPTOOLPY_FLASHSIZE_8MB` and use 8 MiB in the application's flash-size assertion. Merge the bootloader, partition table and application at 0x1000, 0x8000 and 0x10000.
- Basic v2.7 accepted the 16 MiB header and took the distinct 16 MiB Worker flash configuration. The fixed guest observed the real A, B and C edges after a boot in both 4 and 16 MiB configurations.
- VoiceS3R completed audio output in the earlier fixed guest. The microphone guest consumes 16 kHz PCM16 WAV and reports 3158 nonzero bytes and a 255-byte range. The first attempt hit the verified UART0 install conflict in the boot script. Use the earlier qualified speaker image as the base and retain its console-safe boot script while replacing main.py with `tests/browser-qemu/board_display/browser_voices3r_mic.py`.
- AtomU and Echo remain outside the browser workbench admission. Separate Arduino/M5Unified builds reach board identification 130 and 142, then stop producing the guest heartbeat around 0.12 and 0.14 seconds. A different UIFlow2 test image stalls around 0.50 and 0.52 guest seconds in the earlier record. Tear down still completes. Stock firmware and audio on classic Echo require a working guest and remain unqualified.
- Every passing variant observes one esp32sim DedicatedWorker before the workbench Stop operation and zero afterward.

The reports preserve the manifest, firmware and WASM identities and the actual guest markers. The guest runner is `platform/tests/test_public_esp32sim_board_guest.mjs` and takes fixture files from `M5_BROWSER_MATRIX_FIRMWARE`. Raw firmware is outside the workbench export. On dual-engine boards the retained engine can be selected in the workbench.
