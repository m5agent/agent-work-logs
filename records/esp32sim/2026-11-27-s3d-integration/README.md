# S3-D PaperDIY and PaperS3 integration

PaperDIY and PaperS3 landed in [esp32sim at `d6ae7a67`](https://github.com/m5agent/esp32sim/commit/d6ae7a67809f135c812d5c21504853e682ce6cc4). The annotated milestone is [`m5-milestone-s3d-20261127`](https://github.com/m5agent/esp32sim/releases/tag/m5-milestone-s3d-20261127).

Native virtual-device validation passed PaperDIY 6/6 and PaperS3 9/9 Arduino examples. Both stock UIFlow2 images passed home frame, USB CDC REPL and board input checks. The workspace passed 2004 tests. PaperMono and PaperColor qualification remains open.
