# Repeat the Tab5 checks

Use `esp32sim-p4` from the revision in the [work record](../../board-peripherals.md) and provide the ESP32-P4 rev0 mask ROM through `ESP32SIM_ROM_DIR`. Set `ESP32SIM_P4` to the absolute executable path. Compile the OCR helper with `swiftc frame-text.swift -o frame-text` on macOS. The checker also needs `sips`, Python 3 and Mtools.

Build the standalone Arduino blocks from the pinned Tab5 documentation using M5Stack Arduino 3.2.5, M5Unified 0.3.0, M5GFX 0.3.0 and FQBN `m5stack:esp32:m5stack_tab5`. Place the merged images at `firmware/<case>/sketch.ino.merged.bin` as named in the scripts. Save the unmodified speaker build exit code as `firmware/speaker-1/result.json`. Build a separate copy with the first line changed from `##include` to `#include` at `speaker-1-corrected/build/sketch.ino.merged.bin`. The two additional board sketches and the SDK USB probe are included here. The register-level USB probe is [one directory above](../msc-probe.ino). Build their merged images at the paths in the scripts.

Place the original UIFlow2 and Maker Fighter images and the C6 firmware segments under `firmware/` with the filenames in the runner. The [launcher manifest](../../run.json) and [USB manifest](../../evidence/usb-host-summary.ndjson) list known image hashes. Provide a writable 64 MiB card seed with the FAT volume starting at byte 1048576, with PNGs under `TestPicture01.png` and `TestPicture02.png`. The second seed also includes the displayed files `tab5_test_picture_1280_x_720_01.png` and `tab5_test_picture_1280_x_720_02.png`. They are 1280×720 solid RGB PNGs with source colors (32, 88, 200) and (176, 72, 32). Provide `mic-tone.wav` and `mic-silence.wav` as ten seconds of signed 16-bit mono PCM at 17 kHz. The tone uses a 733 Hz sine wave with amplitude 4,096.

Run `./run_all_tab5.sh`. It writes serial logs, frame PNGs, image and runtime hashes, controller traces and WAV outputs. Run `python3 check_tab5.py ./frame-text` to recheck completed captures. It emits one JSON verdict per case.
