## esp32c5 board present in both releases
/tmp/boards_3.3.13.txt:171:esp32c5.name=ESP32C5 Dev Module
/tmp/boards_4.0.0.txt:401:esp32c5.name=ESP32C5 Dev Module

Interpretation:
- 3.3.13 default esp32p4 target = esp32p4_es (chip revision < 3); 4.0.0 default = esp32p4 (revision >= 3).
- Both releases expose menu.ChipVariant with both options prev3 and postv3, so the FQBNs
  esp32:esp32:esp32p4:ChipVariant=postv3 and :ChipVariant=prev3 are valid on both.

Consequence: the postv3 rows link the esp32p4 SDK and the prev3 rows the esp32p4_es SDK,
so the two P4 rows per release are different builds, not duplicates. The CI sketch sizes
differ accordingly (see new-matrix-rows-builds.txt).
