2) M5GFX CoreP4X power_on drives M5IOE1 G12 (pin 11, reg 0x06 bit 0x08) high
   and then delays 150 ms:

   src/board_detect/m5/pmic_ops.hpp:17   ioe1_i2c_addr = 0x4F
   src/board_detect/m5/pmic_ops.hpp:25-28 pm1_family_devices[0]=0x6E, [1]=0x4F
   M5IOE1 pin numbering: src/utility/M5IOE1_Class.hpp:20-31
     gpio12 = 11  -> register 0x05 + (11>>3) = 0x06, bit 1<<(11&7) = 0x08
   => In a normal CoreP4X boot the rail has been on for >= 150 ms when
      Power.begin() reads it, so rail_was_on is true and no wait is added.
