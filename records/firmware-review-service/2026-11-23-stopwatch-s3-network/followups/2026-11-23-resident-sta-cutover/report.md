# 常驻切换与原版复审

模拟器和 Reviewer 的本地与远端 Git `main` 已推进至候选验证记录中的源提交。模拟器主线 CI 完成。当前部署采用冻结源码和此前同架构运行时。浏览器导出采用同一已核验清单。

Device Service 的工作台和审核执行端均通过实际启动验证。切换后服务角色、配置、认证与历史读回一致，保存 39 条工作台会话、100 条审核后端会话。Reviewer 使用生产 Python 3.9.6 的隔离预检通过，基础切换后报告 OpenAPI 0.32.0，并保留 208 条旧审核任务。三份证据 ZIP 的字节摘要一致。

Reviewer 保留切换前已有的线上识别补丁。最终纯主线套件 341 项通过。叠加原常驻补丁的切换前后均有同样两项输入语义判定差异，本轮没有新增差异。

Linux 管理 worker 接续原 Core2 和 CardputerDict ADV 两个历史会话。再导出的证据 ZIP 中 22 个非 manifest 成员的摘要完全一致，manifest 更新了恢复和导出记录。SD 和 PCM 接口分别读回 5431 和 84992 字节，与先前数据一致。原始 ZIP 保持归档。旧 worker 确认租约为零后正常停机并卸载，原封存包保留用于回滚。

常驻 Reviewer 最终切换到 OpenAPI 0.32.1，启用原版 StopWatch 的专用复审档案。一般 ESP32-S3 快照保留主后端路线。将新建的独立快照任务原地复跑，原 208 条审核及其抽查证据仍保留。使用同一原版和独立 Flash 的实验 NVS，六步检查、界面与 60 秒观察通过。最终抓包显示一次完整 DHCP、一个租用地址、零双向应用流量。结论保留 `SIM_PARTIAL / E_NETWORK_PARTIAL`。完成后活动租约与 Burner 提交均为零。

出厂热点配网与 S3-watch WPA2/HTTP 属于独立运行验证，已有凭据的复审结果仅适用于已配网状态。
