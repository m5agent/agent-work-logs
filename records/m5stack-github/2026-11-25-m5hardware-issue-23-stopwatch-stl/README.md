## 结论

复核成立：`Products/C152_StopWatch/Structures/StopWatch.stl` 的总高为 15.000 mm，屏幕玻璃确实没有建模，
前壳在 r ≤ 23.70 mm 范围内 X 最高只到 11.550 mm。官方尺寸图 `C152-StopWatch-model-size.pdf` 标注总高 15.5 mm，
且没有标注屏幕窗口直径与高出边框的高度。缺失件可由模型自身反推：座圈 X=14.300、内孔 Ø47.40、座外径 Ø49.06、
上沿内径 Ø49.08，因此 Ø49.08 × 1.20 mm 的圆片（底面 14.300、顶面 15.500）正好补到 15.5 mm 并高出边框 0.50 mm。
文件内另有第二份 8534 三角形的整机副本，沿 −Z 平移，可整体删除。

结论仅覆盖模型几何与图纸标注；未做 C152 实机高度测量，也未在 CAD 软件中重建或重新导出该件。

## 关键证据

- 模型解析：`evidence/stl_analysis.py` + `evidence/stl_analysis_output.txt`
  - 17068 三角形；整机 8534 + 位移副本 8534。
  - 整机包围盒：X 0.000..15.000，Y/Z ±25.973（= Ø51.95）。
  - X>14.99 的最高面仅为 r 24.541..24.973 的环（Ø49.08..49.95）。
  - X=14.300 的座圈：r 23.700..24.530（内孔 Ø47.40，座外径 Ø49.06）。
  - r≤23.69 内最高 X = 11.550，故窗口是通孔、玻璃缺失。
  - 位移副本：X 0.000..15.000、Y ±25.973、Z −208.329..−43.032；四个零件分别沿 −Z 平移
    −69.006 / −109.600 / −189.626 / −220.703 mm。
- 图纸：`evidence/C152-StopWatch-model-size.png`（PDF 渲染）与 `evidence/drawing-dimensions.txt`
  - 标注 15.5、Ø51.95、40、25.46、4-Ø5、2-Ø4、2-Ø2.2、R1、R2；屏幕窗口直径与 0.5 mm 台阶未标注。
