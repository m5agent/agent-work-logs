# C152 StopWatch STL 模型复核

## 1. 背景

`m5stack/M5_Hardware#23`（作者 ciniml）报告：`Products/C152_StopWatch/Structures/StopWatch.stl` 缺少屏幕玻璃，
导致模型总高 15.0 mm，而实机与尺寸图都是 15.5 mm；并请求补充玻璃几何、在图纸上标注窗口直径，
以及确认文件内位于 Z −208.3..−43.0 的 8534 个三角形是否为多余本体。

## 2. 方法

只做静态几何复核，不修改任何仓库、不接触实机：

1. 取固定版本文件：
   `https://raw.githubusercontent.com/m5stack/M5_Hardware/067ddd8fa3cf17506dba4769e50237daf21359db/Products/C152_StopWatch/Structures/StopWatch.stl`
   - 80 字节头 `solid 00-STOPWATCH_ASM_100`；`uint32` 计数 17068；文件 853484 字节 = 84 + 50 × 17068，二进制 STL。
   - SHA256 `48b292c76f929acb75868cba47ccda86800fbff7cfff172161df64ff87f220d5`。
   - 与 `master` 当前 blob `e4ff3f7febe0116d817950ee3effbeba5005dd00` 相同（`git hash-object` 一致），
     即缺陷在当前 master 上仍存在。
2. 用标准库解析三角形，按 STL 约定取 X 为高度轴、`r = hypot(Y, Z)` 为半径，统计各半径带的最高 X，
   并按 1e-3 mm 量化顶点、并查集聚类成岛，用于分离整机副本。
3. 渲染官方尺寸图 PDF（`https://m5stack-doc.oss-cn-shenzhen.aliyuncs.com/1242/C152-StopWatch-model-size.pdf`），
   逐项核对标注。

注：该 PDF 的正文已转为矢量轮廓（无文本对象），因此只能渲染后目视核对，不能文本抽取。

## 3. 结果

### 3.1 总高与最高面

| 项 | 实测 |
| --- | --- |
| 全局高度轴范围 | X 0.000 .. 15.000 mm |
| 整机平面尺寸 | Y/Z ±25.973 mm（Ø51.95，与图纸 Ø51.95 一致） |
| X>14.99 的顶点 | 675 个，r 24.541 .. 24.973（Ø49.08 .. 49.95），仅边框环带 |

即最高面是前壳上沿环带，总高 15.000 mm，与作者所述一致。

### 3.2 屏幕窗口与玻璃座

| 项 | 实测 |
| --- | --- |
| 座圈平面 | X = 14.300（顶面） |
| 座圈半径 | r 23.700 .. 24.530（内孔 Ø47.40，座外径 Ø49.06） |
| 上沿内孔 | r = 24.541（Ø49.08） |
| r ≤ 23.60 / 23.65 / 23.69 内的最高 X | 11.150 / 11.150 / 11.550 |

r ≤ 23.69 内没有任何高于 11.550 的几何，说明窗口在前壳上是通孔，玻璃既不在座圈上也不在更高处。
作者给出的 r ≈ 23.7（座内缘）、r ≈ 24.5（座外缘）、z ≈ 14.3（座面）、z ≈ 11.5（窗口内最高件）
四项数值均被独立复现。

### 3.3 缺失件可反推的尺寸

以座圈为基准：Ø49.08 的圆片，底面 X = 14.300，顶面 X = 15.500，厚度 1.20 mm，高出上沿 0.50 mm。
该值同时满足：

- 总高 15.5 mm（图纸标注）；
- 侧视图中屏幕面高出边框约 0.5 mm；
- 前视图中约 Ø49.1 的圆 —— 与上沿内孔 Ø49.08 吻合，说明该圆画的是玻璃外缘，而不是 Ø47.40 的透光孔。

因此图纸"约 Ø49.1"的换算结论与网格自身尺寸一致，不需要额外假设玻璃直径。

### 3.4 多余本体

按并查集聚类得到 8 个岛，恰好是 4 个零件 × 2 份：

| 零件三角形数 | 位移（仅 −Z） |
| --- | --- |
| 7256（主体） | −69.006 mm |
| 458 | −220.703 mm |
| 428 | −189.626 mm |
| 392 | −109.600 mm |

位移副本合计 8534 三角形，包围盒 X 0.000..15.000、Y ±25.973、Z −208.329..−43.032，
与作者给出的"第二组 8534 个三角形、Z −208.3..−43.0、X 0..15、Y ±26"完全一致。
四份零件各自平移量不同，是同一整机的重复拷贝，可整体删除而不影响正本。

### 3.5 图纸标注

渲染后可读到的标注只有：15.5（总高）、Ø51.95（外形）、40（宽）、25.46（孔距，两个方向）、
4-Ø5、2-Ø4、2-Ø2.2、R1、R2。屏幕窗口直径与玻璃高出边框的 0.5 mm 均未标注，
因此 issue 第 2 项请求（补充窗口直径与高出量）的前提成立。

## 4. 影响与建议

- 影响面：仅模型文件。凡是按该 STL 贴合屏幕做外壳/夹具的设计，会得到 0.5 mm 的高度误差，
  并在屏幕上留出 15.0−11.55 ≈ 3.45 mm 的空腔（作者描述的镜片夹具场景即属此类）。
- 目录内只有 `StopWatch.stl`，没有 STEP/F3D 等参数化源文件，因此修复应在 M5Stack 的源 CAD 中补件后重导出；
  若短期无法重导出，可在 STL 中直接补一个 Ø49.08 × 1.20 mm、Z 方向落在 14.300..15.500 的圆片，
  并在该目录 README 中注明玻璃未建模。
- 同时建议删除 −Z 方向的整机副本，避免下游导入时出现重复实体。
