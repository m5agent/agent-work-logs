# 派生证据

- [双板原生 PCM](cardputer-native-pcm-summary.redacted.json)包含两个来宾的输入夹具 SHA-256、直接读取与数字 DMA 输出指标，移除工件标识。
- [保留 PCM 和 ACL](cardputer-retained-pcm-acl-summary.redacted.json)记录工作进程重启后的数字输出 SHA-256、HTTP 状态与 ZIP 音频成员状态。
- [CoreS3 U024 审核](cores3-u024-review-summary.redacted.json)包含两次 dry-run 的总线计数、独立来宾读值、证据 ZIP 摘要和异常对照。
- [PaperS3 首次完整对照](papers3-first-comparison-summary.redacted.json)包含独立启动失败、12 次触摸和被动面板计数。
- [PaperS3 匹配对照](papers3-flat-panel-summary.redacted.json)包含六次接触的 ET047 计数、主机帧请求和脱敏的控制器读写摘要。

每个派生文件保留其上游摘要的字节数与 SHA-256。 [归档清单](../run.json)
