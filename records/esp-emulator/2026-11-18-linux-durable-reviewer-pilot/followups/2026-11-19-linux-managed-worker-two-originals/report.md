# 执行与独立复核

## 固定环境

主机运行 macOS ARM64 Reviewer 0.29.1，源提交为 `3a45e3dd59c2163e0ffd8f948a484a8213b6b82b`。在 Apple Virtualization 启动的无网卡 Linux ARM64 来宾中运行 Device Service 1.99.3，源提交为 `2a7f979c0c7e67420d8b790a3cfdb692702abf05`。同一 Xtensa ELF 和两边 API 合约的完整散列列在机器可读证据中。主机侧 VSOCK 桥采用有限审核路由，调用需要审核凭据；来宾 ADV 的 SNTP 和 HTTPS 使用隔离测试中批准的主机转发路径。

复现时为单个受管 worker 独占持久卷，在无需通知外部系统的保存快照方式分别登记原始两个 BIN。第一代接收 ADV，取回数据面和停止后只读证据，等待活跃租约清零；替换来宾后读取上一代已停止会话，继续从同一 Reviewer 提交 Core2 原始应用。随后单独退出并重开同一 Reviewer 数据库，逐项比对历史、事件和证据。对每次来宾关闭独立收集 Device Service 退出、控制器停止回调和宿主端点撤下的回执。

## A2 桥与两份原版审核

| 环节 | 结果 | 实测 |
| --- | --- | --- |
| 认证与独占 | PASS | OpenAPI 与 1.99.3 精确相等，匿名和错误认证 HTTP 401，范围外读请求 HTTP 403，另一控制器在同卷活跃时被拒绝 |
| CardputerDict 0.5.0（Cardputer ADV） | SIM_VERIFIED | 复核原始 BIN、归一化 Flash 与 OTA0；重新解析同会话 PCAP，确认 SNTP 和 TLS 请求与响应；有效 PCM 84,992 字节，缓存 MP3 10,605 字节 |
| 2048（Core2） | SIM_VERIFIED | 用固件固定的启动依据归一化 app-only BIN；ZIP 中 `0x10000` 的应用字节与原版精确一致；对每次滑动重算合法移动与新出现的一枚方块，四个方向各两次均 PASS |
| 第一代至第二代 | PASS（限定） | 主机桥接端点与 worker 身份保持一致，确认实际第一代来宾退出回调、第二代启动。采样窗口记下 60 次 HTTP 200 和 46 次 HTTP 503，完整服务排空在这一代没有直接证明 |
| 空闲 Reviewer 重开 | PASS | 相同数据库和第二代 worker，保留两条任务与 36 个事件、证据精确，SQLite 完整性检查通过，占用会话与待恢复创建意图均为零 |
| 第二代最终关停 | FAIL | 停机命令在共享文件系统中读到截断的 JSON，未到达完整关停回执；控制器确认中止、端点撤下并隔离此卷，检查拒绝正常启动 |

独立复核直接重开了三个 Reviewer ZIP，逐个核对 33 个清单载荷的 CRC、长度和 SHA-256，绑定原 BIN、归一化 Flash 与同一会话，再从实际 PNG 重算全部八次棋盘变化。ADV 另一个停止后即时 Device ZIP 由原运行收集器在内存中检查，并记录其完整散列与成员数，记录未把它计入三个独立重读的 ZIP。A2 最终关停前另外验证了两个已停止会话的设备归档 22 个成员和 Flash 散列，活跃租约为零；这只证明故障前的数据保留。

## A3 有序停机修正与复核

A3 在独立测试卷复跑相同的 Reviewer、Device Service 和原版固件。每次停机发布绑定当前代次、来宾启动身份与控制器实例的独立命令文件，来宾只读取本代文件。逐代重读准备、关停命令、Device Service 正常退出及 Apple Virtualization 启动与结束回执，确认两代均正常停机、租约为零。在相同宿主端点与持久卷接管后，worker 身份保持一致；最终端点撤下、持久卷锁释放。

| 环节 | 结果 | 实测 |
| --- | --- | --- |
| ADV 在第一代播放，第二代重读 | SIM_VERIFIED | 独立读取停止后 Device ZIP 的 11 个清单载荷，PCM、PCAP 和网络证据与 Reviewer ZIP 逐字节相同；换代前后同一已停止会话的另一份设备归档 15 个清单载荷长度与 SHA-256 全部一致 |
| Core2 第一次 | SIM_PARTIAL | 八次拖动都受理且画面变化，四方向均有合法棋盘变化；第八次向下拖动的两帧相同，但左下角数值 16 的字形覆盖三个固定取样点，颜色未被棋盘检测器识别。保留当时的部分结论和全部 41 个旧证据文件 |
| Core2 同参数复跑 | SIM_VERIFIED | 同一审核任务保存第一次尝试后再跑，原 BIN、归一化 Flash 和验证参数相同；停止后 ZIP 与应用字节、两帧棋盘和四方向各两次合法移动全部逐项核对 |
| Reviewer 重开 | PASS | 同一 SQLite 文件，重读两条审核任务与 52 条事件，保留 ADV 证据和 Core2 两次尝试；数据库完整性通过，零活跃租约 |

A3 证明新命令交接在这次两代受管运行中正常完成。Core2 棋盘检测器仍有已复现的固定像素取样限制，A3 没有改动检测器或固件。这两段原版审核属于受控干跑，后续能否复现所有随机棋盘状态仍取决于程序观察范围。

## 验证范围

验证覆盖专用 Apple Virtualization 来宾与测试状态。真机、浏览器、公网通用访问、常驻路由切换、主动任务中断恢复及 Burner 提交均为 `NOT RUN`。原始 ZIP、网络捕获、数据库和进程日志留在私有证据存储。本文公布可核对的固件、运行时和回执散列、有限数据面观察及关停范围。
