# Dial 原版 8 ms 漏选的同会话 GPIO 读回

- 日期 `2026-11-19`（UTC+08:00）
- 结果 `PARTIAL`，原版显式 8 ms 偶发漏选。35 ms 对照通过。
- 工作类型 `report`，延续 1.99.0 原版旋钮验证
- 环境 macOS ARM64、Device Service 1.99.0，原生 QEMU Dial，PORT.B AudioPlayer U197 七轨索引夹具

## 结论

未修改的 vinylM5Dial 1.0 R1F30 在冻结发布运行时出现 1 次 8 ms 漏选。+16 格从第 6 轨开始，控制器交付全部 64 个 GPIO 边沿，原版却通过有效的 N9301 UART 指令选了第 7 轨，预期第 1 轨。

另一个独立会话使用固定的只读 GPIO 诊断版。两次同类漏选中，各有一个持续 8.911 或 9.449 毫秒的 Gray 相位完全没有被固件读取。按实际读值和原版状态表重放，两次均只计 +60，吻合来宾串口选到第 7 轨。第三次漏读由原版相位状态表补偿，此次重放仍为 +64，选曲正确。

## 证据

- 发布版 8 ms 选曲 19/20，诊断版 18/20。两轮各自 20 个 35 ms 前置对照均正确。同起始轨、同方向、同 +16 格的独立显式 35 ms 发布版对照通过 6/6。
- 诊断版 8 ms 检查了 6,474 对实际原版 GPIO 读值，35 ms 前置对照为 6,396 对。两脚读取均在同一相位内，35 ms 对照无漏读。
- 原版、原生运行时和 API 证据绑定到每次运行。全部会话释放 Flash 和租约。
