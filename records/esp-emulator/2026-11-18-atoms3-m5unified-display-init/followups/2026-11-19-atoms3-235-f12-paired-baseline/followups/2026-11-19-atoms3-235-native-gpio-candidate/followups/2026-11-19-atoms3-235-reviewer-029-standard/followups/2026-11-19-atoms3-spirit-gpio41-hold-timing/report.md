# Spirit Level v1.0.0 原版按键、归零及重置

前序 Reviewer 运行已通过原版应用就绪，描述中的屏幕按压仍待验收。AtomS3 的显示组件下方按压触发实体 BtnA，由 GPIO41 接收。作者 v1.0.0 源码以 BtnA 的单击切换模式，判断释放事件中的 600 毫秒和 2200 毫秒以选择归零与重置。发布方完整 BIN 609,856 字节的 SHA-256 与本次两轮输入一致。 [前序标准审核](../../README.md) · [作者 v1.0.0 发布](https://github.com/ElectroIoT/M5-AtomS3-Spirit-Level/releases/tag/v1.0.0) · [固定版本按键实现](https://github.com/ElectroIoT/M5-AtomS3-Spirit-Level/blob/095e0174a7529be52ffa53403c64dd2e105fc1b6/src/main.cpp#L289-L295)

两轮保持同一原版、同一份 8 MiB 规范化 Flash、同一 ROM 和同一签名 Xtensa QEMU。A3 使用 Device Service 1.99.2 源码 `c25fdfc9`。A4 在同一个冻结基底的独立副本应用 `cd129680` 的精确差异，使用 Device Service 1.99.3 候选。候选允许这个原生机型的 BtnA 进入已有按键语义路径，QEMU 字节一致。记录包含设备 API SHA-256 和补丁后输入模块 SHA-256。 [运行与摘要](evidence/atoms3-spirit-gpio41-timing.summary.json)

## 实验过程

在两个独立原生会话中，用约 +0.75g 的模拟 MPU6886 X 轴输入形成 BUBBLE 的 +36.9°。通过对应的寄存器读取核对固件获得的传感器输入。无按压对照的图像逐字节一致。分开请求 `key a down` 与 `key a up` 的短按对照，得到 BUBBLE → TUBE → ANGLE → BUBBLE。用 `POST /api/v1/sessions/{id}/input` 分别提交宿主边沿和候选按键动作，逐个比对回执、GPIO41 低高变化、前后画面和输入稳定性。

A3 的宿主按下与释放请求间目标为 0.600 秒。观察到 GPIO41 低电平持续 611.131 毫秒，固件显示 `ZERO SET`，在 MPU 输入维持倾斜时稳定显示 `−0.0°`。原采集器要求与开机 `+0.0°` 图像逐像素一致，因此曾标为 `CALIBRATION_UNCONFIRMED`。独立回读核对了提示以及稳定画面。相对初始中立画面，稳定归零画面仅在一个 1×5 像素的符号区域有差别。原回执原样留存。

A4 每项使用一次 `kind=button, control=a, action=hold` 请求。服务以虚拟时钟的 `queued` 回执接收固定时长，GPIO41 日志提供实际的低高边沿，其间隔由宿主观测。屏幕和 MPU 读取独立确认应用效果。

| 请求虚拟时长 | 宿主观察的 GPIO41 边沿间隔 | 原版来宾结果 |
| --- | --- | --- |
| 600 ms | 599.720 ms | 仍为 +36.9°，与无按压控制帧一致 |
| 610 ms | 609.986 ms | 仍为 +36.9°，与无按压控制帧一致 |
| 700 ms | 699.032 ms | 出现 `ZERO SET`，稳定为 −0.0° |
| 2200 ms | 2200.585 ms | 出现 `ZERO SET`，保留归零偏移 |
| 2350 ms | 2350.444 ms | 出现 `ZERO RESET`，恢复原倾角 +36.9° |

700 毫秒归零后，在相同会话把传感器回到零倾斜，屏幕显示 −36.9°，再次倾斜到相同输入得到稳定带符号零。2350 毫秒重置后，倾斜画面恢复到控制帧；再次回中立后，与开机中立画面逐字节一致。这验证了偏移的可见改变和恢复。

## 证据范围

A3 与 A4 使用相同原版，但宿主配对边沿和虚拟计时输入属于两种不同路径。这些采样足以支持已发生的精确结果。其余时长、一般触发阈值及屏幕机械结构的实机表现仍待测。A4 的短按控制采用宿主配对边沿。候选 Reviewer 标准运行、断电后的偏移持久化、浏览器和生产切换未执行。

每轮均核对设备回执、模拟控制器日志、原版应用区域、PNG 和证据 ZIP，从而将读回与同一会话绑定。两个 ZIP 各 8 个清单成员通过哈希和 CRC 检查。访客与专用服务均已退出，保留停止历史，Flash 已释放，活动租约为零。Burner 未提交。公开摘要保留来源、派生的时序和证据哈希，省略原始包、日志、端点和独有标识。 [脱敏证据摘要](evidence/atoms3-spirit-gpio41-timing.summary.json)
