## 虚拟设备与宿主端验证

ARM64 Linux 虚拟机从只读 ext4 输入读取本轮 ZIP，断网运行打包后的查找和 SKU 工具。虚拟机核验 4,409 个文件与 6,425 篇索引正文，复核 2,029 篇合并正文的偏移，正文未发现 Coming Soon 标记。Tab5 的官网查询和 K145 的产品查找返回正确资料。Chain DLight 中文及英文教程均可按 URL 定位并用 `--read` 读取，正文含设备识别及示例标记。内核、输入盘、控制台和样本文档摘要见证据。

宿主端把包内正文与冻结输入逐字节对比。抽查英日文 Tab5、英中 Chain DLight 与 Chain ENV Arduino 教程，以及日文 Dial v1.1。9 项跨语言 SKU 查询通过。3 条 Coming Soon 路由和旧 DLight 拼写路径均未命中。Skill 元数据校验通过。
