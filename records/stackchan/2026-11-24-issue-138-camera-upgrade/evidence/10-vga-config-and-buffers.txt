=== Buffer arithmetic ===
VGA YUV422 frame: 640 * 480 * 2 = 614,400 bytes.
QVGA YUV422 frame: 320 * 240 * 2 = 153,600 bytes (4x smaller).
StackChan peak preview path at VGA: DVP buffer 614,400 + captured copy 614,400 +
RGB565 preview 614,400 = 1,843,200 bytes (~1.8 MB PSRAM), versus ~460,800 bytes at QVGA.
Arduino/esp32-camera RGB565 VGA: 614,400 bytes per frame; fb_count=2 -> 1,228,800 bytes.
