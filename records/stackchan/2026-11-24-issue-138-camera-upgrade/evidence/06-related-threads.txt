## #70 visual gaze following (CLOSED) — on-device headroom finding
70 [Feature Request] 支持对话时视觉跟随 / visual gaze following during conversation CLOSED comments=3
We built an experimental local-first implementation here:

https://github.com/xuruiray/stackchan-local

The main idea is to move the heavy computation off the ESP32. In practice, the ESP32 does not have enough headroom to run stable real-time image recognition together with the existing avatar, audio, servo, camera, Wi-Fi, and UI workload.

So our approach is:

- StackChan hardware captures low-FPS camera frames and sends them to a local desktop daemon over LAN WebSocket.
- The desktop daemon runs face detection / tracking locally on the computer.
- The daemon sends only lightweight motion targets back to the hardware.
- The hardware focuses on expression: avatar, servos, RGB, audio playback, sensors, and companion state.
- Codex / MCP integration also runs on the computer, so StackChan behaves more like a desktop pet: the computer is the brain, and the hardware is the expressive body.
