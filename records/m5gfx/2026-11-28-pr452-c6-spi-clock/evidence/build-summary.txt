# 构建记录

## 工具链

- macOS arm64
- `arduino-cli 1.6.0`（Homebrew）
- `esp32:esp32 3.3.13`（Arduino-ESP32 3.3.13 / ESP-IDF 5.5.5）
- 两个只读库树：
  - base：`m5stack/M5GFX` `603092aab60e32fadd1d73abd472068a35e189e8`（develop，PR base）
  - head：`m5stack/M5GFX` `e1666e9c175725b426a7aef9e4b17622f1d9813a`（PR head）

## 命令（路径已替换为占位符）

```
arduino-cli compile --fqbn esp32:esp32:arduino_nesso_n1 \
  --library <M5GFX-tree> --output-dir <out> <sketch-dir>
```
